# My-Learning — Two-Person Upskilling Program

A gated, evaluated upskilling program for **two learners** building one shared app (**Renewly**), each with a distinct TypeScript specialty. Progress is scored weekly and tracked here.

**Board:** [Version 2.0](https://github.com/users/helenasaju71905-droid/projects/1) · **Design spec:** [`docs/superpowers/specs/2026-08-27-upskilling-program-design.md`](docs/superpowers/specs/2026-08-27-upskilling-program-design.md)

## Who's learning what

| | Helena | Thomas |
|---|---|---|
| Role | Primary builder (DB + API heavy lifting) | Coach + co-builder |
| Foundations | TypeScript + Linux (intermediate) | TypeScript + Linux (advanced) |
| Specialty | **Playwright/TS test automation** (SDET) | **MCP server + AI layer in TS** |

Git is learned by doing. Pace: **~8 hrs/week each → ~14–15 weeks**.

## Phases (strict, foundations-gated)

| Phase | Length | Focus |
|---|---|---|
| 0 · Setup | ~1 wk | Environment, repo/branch onboarding |
| 1 · Foundations | ~5 wks | TypeScript roadmap + Linux — **must validate ≥ 70% to advance** |
| 2 · Build Renewly | ~4.5–5.5 wks | DB + API + UI; MCP scaffolding begins |
| 3 · Specialties | ~3 wks | Playwright suite + MCP/AI layer |
| 4 · Ship | ~1.5 wks | CI/CD, deploy, docs, interview prep |
